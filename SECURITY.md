# Security policy

This repository is an experimental prototype. Do not use it to manage real assets, investors, identity data, or funds.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue. Use GitHub's private vulnerability reporting for this repository when available. Otherwise, contact the repository owner through GitHub to arrange a private disclosure channel.

Include the affected commit, relevant files or instructions, and a concise reproduction when possible. Do not include real personal or financial data in a report.

## Security boundaries

- On-chain hashes commit to bytes; they do not establish authenticity, title, or legal effect.
- Issuer and verifier attestations are attributable statements, not independent legal findings.
- Receipt proofs establish inclusion in a Merkle root; they do not prove bank settlement or tax remittance.
- Do not submit real personal data, identity documents, tax identifiers, confidential contracts, or live payment information.

See [README](README.md) for the project's scope and limitations.
